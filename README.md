# GHOMEGA PROTECTOR

Landing page minimalista com palavra central grande e efeito de brilho.

Preview
- Abra `index.html` localmente no navegador para ver a página.
- Arquivo principal: `index.html` (na raiz do repositório).

Como rodar localmente
1. Baixe/clonar o repositório:
   git clone https://github.com/SEU_USUARIO/ghomega-protector.git
   cd ghomega-protector
2. Abra `index.html` no navegador (duplo clique ou arraste para o navegador).

Publicar com GitHub Pages (opção via web)
1. No GitHub, acesse o repositório → Settings → Pages.
2. Em "Source" selecione a branch `main` (ou `master`) e a pasta `/ (root)`.
3. Clique em Save. Aguarde alguns minutos — o link será exibido em Pages (ex.: https://SEU_USUARIO.github.io/ghomega-protector/).

Publicar com GitHub CLI
1. Se ainda não criou o repositório localmente:
   git init
   git add .
   git commit -m "Initial commit"
   gh repo create SEU_USUARIO/ghomega-protector --private --confirm
   git push -u origin main
2. Habilitar Pages via CLI não é necessário se usar a UI; basta ativar em Settings → Pages.
